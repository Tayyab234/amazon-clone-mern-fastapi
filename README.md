# Amazon Clone (React + FastAPI)

A responsive Amazon-inspired eCommerce web application built while learning JavaScript and full-stack development.

## Features

- Responsive Home Page
- Shopping Cart Page
- Orders Page
- Order Tracking Page
- Dynamic Cart Management
- Backend API with FastAPI
- MongoDB Database Integration
- Store User Cart Products
- Store Placed Orders
- Fetch Orders from Backend
- Responsive UI using JavaScript

## Tech Stack

### Frontend
- JavaScript
- React
- HTML
- CSS

### Backend
- FastAPI
- Python
- MongoDB

## Project Structure

```bash
frontend/
backend/
```

## Backend Setup

Navigate to backend folder:

```bash
cd backend
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run FastAPI server:

```bash
uvicorn main:app
```

Backend will run on:

```bash
http://127.0.0.1:8000
```

## Frontend Setup

Navigate to frontend folder:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```
